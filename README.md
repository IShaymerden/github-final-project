# Simple Interest Calculator

## Description
This project is a simple interest calculator written in Bash. It calculates simple interest based on the principal amount, annual interest rate, and time period.

## Formula
Simple Interest = (Principal × Rate × Time) / 100

## Features
- Accepts user input for principal, rate, and time.
- Calculates simple interest.
- Displays the calculated result.
- Easy to use through a terminal.

## Technologies Used
- Bash Shell
- Git
- GitHub

## How to Run
1. Clone the repository.
2. Open a terminal in the project folder.
3. Run the following command:

```bash
bash simple-interest.sh
```

4. Enter the principal amount, interest rate, and time period.

## Example
Principal: 1000

Rate: 5

Time: 2

Simple Interest: 100
